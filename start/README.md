## 🚀 البدء السريع

### المتطلبات
- Node.js 18+
- pnpm (أو npm)

### التثبيت

```bash
# تثبيت المتعلقات
pnpm install

# تشغيل خادم التطوير
pnpm run dev

# بناء للإنتاج
pnpm run build

# معاينة الإنتاج
pnpm run preview
```

```

```

## 🎨 التصميم

- **نمط التصميم:** Luxury Minimalism
- **الألوان:** ذهبي وأسود مع تدرجات ناعمة

## 🔧 التكنولوجيا

- **React 19** - مكتبة واجهات المستخدم
- **TypeScript** - لغة البرمجة
- **Tailwind CSS 4** - أنماط CSS
- **Vite** - أداة البناء
- **shadcn/ui** - مكونات واجهة المستخدم
- **Framer Motion** - الحركات والانتقالات
- **Wouter** - التوجيه (Routing)
